Présentation du projet

Dans le cadre du module de communication web, j'ai conçu et développé un site web complet pour une agence de voyage fictive. L'objectif était de produire un site professionnel, structuré et navigable, en appliquant les bonnes pratiques HTML5 et CSS3.

Le site présente des destinations, des offres de voyages et un formulaire de contact, le tout organisé sur plusieurs pages liées entre elles par une navigation cohérente.

Fonctionnalités

  • Architecture multi-pages avec navigation fluide entre les sections
  • Page d'accueil avec présentation visuelle des destinations phares
  • Page de listing des offres avec filtres par destination
  • Page de détail d'une destination avec galerie d'images
  • Formulaire de contact avec validation HTML5 native
  • Design entièrement responsive, adapté mobile et desktop
  • Mise en page avec Flexbox et CSS Grid

Difficultés rencontrées

La cohérence visuelle entre les pages a été le principal défi : maintenir un style uniforme sans framework CSS impose une organisation rigoureuse du fichier de styles et une bonne utilisation des variables CSS.

L'adaptation mobile a également demandé beaucoup d'itérations, notamment pour la navigation et la grille des destinations.
