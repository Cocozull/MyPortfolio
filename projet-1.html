Présentation du projet

Dans le cadre d'une étude comparative d'approches algorithmiques, j'ai développé un mini jeu vidéo en C++. L'objectif était de concevoir un jeu fonctionnel en console tout en expérimentant différentes stratégies algorithmiques pour mesurer leur impact sur les performances et la lisibilité du code.

Ce projet m'a permis de mettre en pratique les concepts de la programmation orientée objet appris en cours, en les appliquant à un contexte ludique concret.

Fonctionnalités

  • Boucle de jeu principale avec gestion des tours et des états
  • Système de collision et détection des interactions entre entités
  • Gestion des entrées clavier en temps réel
  • Système de score et de progression du joueur
  • Plusieurs niveaux de difficulté
  • Comparaison de deux approches algorithmiques pour une même mécanique

Extrait de code

// Boucle de jeu principale
void Game::run() {
  while (isRunning) {
    handleInput();
    update(deltaTime);
    render();
    deltaTime = clock.restart().asSeconds();
  }
}

// Détection de collision (approche O(n²))
bool checkCollision(Entity& a, Entity& b) {
  return a.x < b.x + b.width  &&
         a.x + a.width  > b.x  &&
         a.y < b.y + b.height &&
         a.y + a.height > b.y;
}

Ce que j'ai appris

Débogage C++Utilisation de GDB et Valgrind pour traquer les fuites mémoire et erreurs.

Difficultés rencontrées

La principale difficulté a été la gestion du temps réel en console, notamment la synchronisation entre les entrées clavier et le rendu. J'ai dû implémenter une boucle de jeu avec un delta time précis pour garantir une expérience fluide indépendante de la machine.

La comparaison des deux approches algorithmiques a également nécessité une rigueur dans la mise en place des benchmarks pour obtenir des résultats comparables.
