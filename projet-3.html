Présentation du projet

Ce projet consiste en la conception complète d'une base de données relationnelle inspirée du fonctionnement réel d'une entreprise. L'objectif était de passer par toutes les étapes de modélisation, de la définition des besoins jusqu'à l'implémentation et l'interrogation de la base.

Le projet couvre la modélisation conceptuelle (MCD), le passage au modèle logique (MLD), la création des tables en SQL, l'insertion de données et la rédaction de requêtes complexes pour répondre à des cas d'usage métier concrets.

Fonctionnalités

  • Modélisation conceptuelle (MCD) avec entités, associations et cardinalités
  • Passage MCD → MLD avec gestion des clés primaires et étrangères
  • Création des tables SQL avec contraintes d'intégrité (NOT NULL, UNIQUE, CHECK)
  • Insertion de jeux de données représentatifs pour les tests
  • Requêtes SELECT avancées (GROUP BY, HAVING, ORDER BY)
  • Jointures multiples (INNER JOIN, LEFT JOIN) entre les tables
  • Sous-requêtes et vues pour simplifier les requêtes complexes

Extrait de code

SQL — schema.sql 
-- Création de la table Employé
CREATE TABLE Employe (
  id_employe    INT          PRIMARY KEY AUTO_INCREMENT,
  nom           VARCHAR(50)  NOT NULL,
  prenom        VARCHAR(50)  NOT NULL,
  salaire       DECIMAL(8,2) CHECK (salaire > 0),
  id_service    INT          REFERENCES Service(id_service)
);

-- Salaire moyen par service
SELECT s.nom_service,
       AVG(e.salaire)      AS salaire_moyen,
       COUNT(e.id_employe) AS nb_employes
FROM   Employe e
JOIN   Service s ON e.id_service = s.id_service
GROUP BY s.nom_service
HAVING COUNT(e.id_employe) > 2
ORDER BY salaire_moyen DESC;

Difficultés rencontrées

La phase de modélisation conceptuelle a été la plus complexe : identifier correctement les cardinalités des associations et éviter les redondances demande une analyse rigoureuse des besoins métier avant d'écrire une seule ligne de SQL.

Les requêtes avec plusieurs jointures et sous-requêtes imbriquées ont également nécessité une bonne compréhension de l'ordre d'exécution des clauses SQL.
